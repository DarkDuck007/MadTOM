# MADTOM: MediaCenter Plugin

The **MediaCenter** plugin (`MADTOM.Plugins.MediaCenter`) provides a modern home media hub for indexing local and network NAS movie/show libraries, direct play streaming, and casting to DLNA/UPnP renderers.

---

## Features

- **NAS & Local Indexing**: Automatic format probing (AV1, HEVC, HDR10+, Dolby Vision).
- **Network Streaming**: Low-latency direct playback and background remuxing.
- **Renderer Control**: Status monitoring and casting control in MADTOM Studio and system tray.
