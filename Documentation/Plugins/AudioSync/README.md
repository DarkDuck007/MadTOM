# MADTOM: AUDIOSYNC Plugin

The **AUDIOSYNC** plugin (`MADTOM.Plugins.AudioSync`) provides synchronized multi-room audio streaming, network clock disciplining (PTP / Precision Time Protocol), and per-endpoint latency buffer calibration.

---

## Features

- **Multi-Room Synchronization**: Manage synchronized audio distribution across PipeWire, Snapcast, PulseAudio, and AirPlay 2 endpoints.
- **Clock Disciplining**: Real-time jitter tracking and sub-millisecond clock drift compensation.
- **Dynamic Tray Status**: Displays master clock lock status and active stream format directly in the MADTOM Console tray menu.
